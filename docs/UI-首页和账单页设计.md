## 设计总纲

| 属性 | 值 |
|------|-----|

## 5. 页面交互流程

### 5.1 首页 — 记账完整流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 1.进入页面 │ → │ 2.输入金额│ → │ 3.选分类  │ → │ 4.点确认  │
│ 默认支出   │    │ 自动聚焦  │    │ 点击选中  │    │ Toast提示 │
│ 选中"餐饮" │    │ 数字键盘  │    │ 高亮边框  │    │ "记账成功"│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                    │
                                                    ▼
                                              ┌──────────┐
                                              │ 5.表单重置│
                                              │ 金额清空  │
                                              │ 分类保留  │
                                              │ 焦点回到  │
                                              │ 金额输入  │
                                              └──────────┘
```

### 5.2 账单列表 — 筛选与操作

```
默认进入 → 显示"全部"账单，按日期倒序分组
     │
     ├── 点击"本周" → 筛选本周数据，按钮高亮
     ├── 点击"本月" → 筛选本月数据，按钮高亮
     ├── 点击"全部" → 恢复全部数据
     │
     ├── 点击账单行 → 展开详情 (显示完整备注、编辑/删除按钮)
     │      ├── 点击"编辑" → 跳转编辑页 (复用记账表单)
```
