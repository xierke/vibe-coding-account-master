## 1. 产品概述

### 1.1 产品背景

市面上的记账工具要么功能繁重（如企业财务软件），要么缺乏有效的统计报表。用户需要一个**简单、直观、清爽**的日常记账工具——快速记录收支，通过报表了解消费习惯，且使用体验温暖舒适不刺眼。

### 1.2 产品愿景

打造一款**轻量、温暖、数据可视化**的 Web 记账应用，帮助用户养成记账习惯，清晰掌握个人财务状况。Web 版作为第一入口，后续平滑扩展到移动端。

### 1.3 核心价值

- **极简操作**：3 秒完成一笔账单记录，降低记账门槛
- **温暖体验**：暖色调配色，视觉舒适，长时间使用不疲劳
- **数据洞察**：周报/月报直观展示收支趋势和消费构成
- **云端存储**：数据云端保存，换设备不丢失
- **响应式设计**：Web 版适配桌面和平板，为移动端扩展预留架构

### 1.4 目标用户画像

| 用户类型 | 特征描述 | 核心需求 |
|---------|---------|---------|
| **职场新人** | 23-30 岁，刚工作，收入不高 | 控制开支、了解钱花在哪 |
| **家庭财务管理者** | 30-45 岁 | 记录家庭收支、分类统计、月度汇总 |
| **学生群体** | 18-22 岁 | 管理生活费、控制消费 |
| **自由职业者** | 25-40 岁 | 区分个人/工作收支、收入来源追踪 |

### 2.2 用户模块（模块一）

#### 2.2.1 注册

| 需求ID | F-USER-001 |
|--------|-----------|
| **功能名称** | 用户注册 |
| **优先级** | P0（必须） |

**功能详情：**
- 支持 **邮箱注册**（V1.0 仅邮箱，后续版本加手机号）
- 注册信息：用户名（唯一，2-20 字符）、邮箱、密码（8-20 位，含大小写字母+数字）
- 密码需二次确认
- 发送邮箱验证码，验证码有效期 5 分钟
- 注册成功后自动登录
- 需勾选同意用户协议和隐私政策

#### 2.2.2 登录

| 需求ID | F-USER-002 |
|--------|-----------|
| **功能名称** | 用户登录 |
| **优先级** | P0（必须） |

**功能详情：**
- 支持 **密码登录**（邮箱+密码）
- 记住我选项（Token 持久化，7 天有效期）
- 密码错误超过 5 次，账号锁定 15 分钟
- 登录成功返回 JWT Token（access_token 15 分钟 + refresh_token 7 天）

#### 2.2.3 密码找回

| 需求ID | F-USER-003 |
|--------|-----------|
| **功能名称** | 密码找回 |
| **优先级** | P1（重要） |

**功能详情：**
- 通过注册邮箱发送重置验证码
- 设置新密码（需二次确认）
- 重置成功后强制重新登录

### 2.3 记账模块（模块二 — 核心）

#### 2.3.1 记一笔

| 需求ID | F-BILL-001 |
|--------|-----------|
| **功能名称** | 快速记账 |
| **优先级** | P0（必须） |
| **描述** | 用户在首页快速记录一笔收入或支出 |

**字段定义：**

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| 类型 | 收入 / 支出（默认：支出） | 是 |
| 金额 | 数字，最多两位小数，范围 0.01 ~ 999,999,999.99 | 是 |
| 分类 | 从预设分类中选择（图标+名称） | 是 |
| 日期 | 默认当天，可选择历史日期 | 是 |
| 备注 | 文本，最多 200 字 | 否 |

**交互要求：**
- 首页即记账页，打开即可记账，减少操作步骤
- 金额输入区域突出（大号字体），自动聚焦
- 支持键盘 Enter 快捷确认
- 确认后 Toast 提示"记账成功"

## 4. 视觉设计规范

### 4.1 色彩体系

**主题定位：温暖、清爽、舒适** — 灵感来源于秋日午后阳光，暖而不燥。

| 色阶 | 色值 | 用途 |
|------|------|------|
| **主色（暖珊瑚）** | `#E07B5A` | 主按钮、主要交互元素、支出标识 |
| **主色-hover** | `#C96A4C` | 按钮悬停 |
| **主色-light** | `#FDF0EB` | 主色浅底背景 |
| **辅助色（暖绿）** | `#7BA587` | 收入标识、正向指标、成功状态 |
| **辅助色（暖蓝）** | `#6B9EB3` | 链接、信息提示 |
| **文字-主要** | `#4A3F3A` | 标题、正文 |
| **文字-次要** | `#8B7E75` | 辅助说明、占位符 |
| **文字-禁用** | `#BFB5AD` | 禁用状态文字 |
| **背景-页面** | `#FAF7F4` | 页面底色（暖白） |
| **背景-卡片** | `#FFFFFF` | 卡片/列表项背景 |
| **背景-悬停** | `#FDF5F0` | 列表悬停态 |
| **边框** | `#EBE3DC` | 分割线、边框 |
| **警告/超支** | `#D4786E` | 超预算、删除等警示操作 |
| **图表色系** | 见分类颜色 | 饼图/柱状图使用各分类对应颜色 |

### 4.2 设计原则

- **无动画**：不使用 transition、animation 等 CSS 动画效果，页面切换和交互均为即时响应
- **响应式**：Flexbox/Grid 布局，桌面端居中最大宽度 1200px，移动端自适应
- **圆角**：卡片 12px，按钮 8px，输入框 8px
- **阴影**：仅卡片使用极淡阴影 `box-shadow: 0 1px 3px rgba(74,63,58,0.08)` — 不用多层阴影，保持简洁
- **间距**：基于 8px 栅格系统（8, 12, 16, 24, 32, 48px）
- **字体**：系统默认字体栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Noto Sans SC", sans-serif`
- **图标**：统一使用 Lucide Icons 或 Heroicons 线性风格

## 5. 技术架构

### 5.1 整体架构

```
┌─────────────────────────────────────────────┐
│              Client (Vue 3 + Vite)           │
│  ┌─────────┐ ┌──────────┐ ┌──────────────┐ │
│  │  UI 组件 │ │ 状态管理  │ │ 本地缓存     │ │
│  │  (Vue)  │ │ (Pinia)  │ │ (localStorage)│ │
│  └─────────┘ └──────────┘ └──────────────┘ │
├─────────────────────────────────────────────┤
│                  HTTPS / REST API            │
├─────────────────────────────────────────────┤
│            Server (Python + FastAPI)         │
│  ┌─────────┐ ┌──────────┐ ┌──────────────┐ │
│  │ Router  │ │ Service  │ │  Repository   │ │
│  │ (路由)  │ │ (业务逻辑)│ │ (数据访问)    │ │
│  └─────────┘ └──────────┘ └──────────────┘ │
├─────────────────────────────────────────────┤
│              MySQL 8.0 Database              │
│  ┌─────────┐ ┌──────────┐ ┌──────────────┐ │
│  │  users  │ │  bills   │ │ categories   │ │
│  └─────────┘ └──────────┘ └──────────────┘ │
└─────────────────────────────────────────────┘
```

### 5.2 技术选型

| 层级 | 技术 | 选型理由 |
|------|------|---------|
| **前端框架** | Vue 3 + Vite | Composition API，开发体验好，构建快 |
| **状态管理** | Pinia | Vue 官方推荐，TypeScript 友好 |
| **路由** | Vue Router 4 | SPA 路由，支持导航守卫 |
| **HTTP 客户端** | Axios | 拦截器支持 Token 自动刷新 |
| **图表** | ECharts (vue-echarts) | 功能全面，支持柱状图/饼图/折线图/热力图 |
| **UI 组件库** | 自定义（无第三方组件库） | 保持风格统一，避免覆盖组件库默认样式的额外工作量 |
| **后端框架** | FastAPI | 异步、自动生成 API 文档、Pydantic 类型校验 |
| **ORM** | SQLAlchemy 2.0 (async) | Python 生态最成熟的 ORM |
| **数据库迁移** | Alembic | SQLAlchemy 官方迁移工具 |
| **认证** | PyJWT + bcrypt | JWT 无状态认证 |
| **数据库** | MySQL 8.0 | 关系型，适合财务数据 |
| **部署** | Docker + Nginx | 容器化部署，Nginx 反向代理 + 静态资源 |

## 6. 数据模型

### 6.1 核心实体关系

```
┌──────────┐       ┌──────────┐       ┌──────────────┐
│   User   │1────*│   Bill   │*────1│   Category   │
│          │       │          │       │              │
│ id       │       │ id       │       │ id           │
│ username │       │ userId   │       │ userId       │
│ email    │       │ type     │       │ name         │
│ password │       │ amount   │       │ icon         │
│ createdAt│       │ categoryId│      │ color        │
│ updatedAt│       │ date     │       │ type         │
└──────────┘       │ note     │       │ isDefault    │
       │           │ createdAt│       │ sortOrder    │
       │           │ updatedAt│       │ createdAt    │
       │           └──────────┘       └──────────────┘
       │                                    │
       │           ┌──────────────┐         │
       │           │   Budget     │         │
       └───────────│              │─────────┘
                   │ id           │  (categoryId
                   │ userId       │   可为 NULL)
                   │ categoryId   │
                   │ amount       │
                   │ month        │
                   │ createdAt    │
                   │ updatedAt    │
                   └──────────────┘
```

### 6.2 表结构

**users 表：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(100) | UNIQUE, NOT NULL | 邮箱 |
| password_hash | VARCHAR(255) | NOT NULL | bcrypt 哈希 |
| avatar_url | VARCHAR(500) | NULL | 头像 URL |
| created_at | DATETIME | DEFAULT NOW() | 创建时间 |
| updated_at | DATETIME | ON UPDATE NOW() | 更新时间 |

**bills 表：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| user_id | INT | FK→users.id, NOT NULL | 用户 |
| type | ENUM('income','expense') | NOT NULL | 收入/支出 |
| amount | DECIMAL(12,2) | NOT NULL | 金额 |
| category_id | INT | FK→categories.id, NOT NULL | 分类 |
| bill_date | DATE | NOT NULL | 账单日期 |
| note | VARCHAR(200) | NULL | 备注 |
| created_at | DATETIME | DEFAULT NOW() | 创建时间 |
| updated_at | DATETIME | ON UPDATE NOW() | 更新时间 |

索引：
- `idx_user_date` (user_id, bill_date) — 按日期查询账单
- `idx_user_category` (user_id, category_id) — 按分类筛选

**categories 表：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| user_id | INT | FK→users.id, NULL | NULL=系统默认分类 |
| name | VARCHAR(30) | NOT NULL | 分类名 |
| icon | VARCHAR(50) | NOT NULL | 图标 (emoji) |
| color | VARCHAR(7) | NOT NULL | 颜色 #RRGGBB |
| type | ENUM('income','expense') | NOT NULL | 收入/支出 |
| is_default | BOOLEAN | DEFAULT FALSE | 是否系统默认 |
| sort_order | INT | DEFAULT 0 | 排序 |
| created_at | DATETIME | DEFAULT NOW() | 创建时间 |

**budgets 表：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 主键 |
| user_id | INT | FK→users.id, NOT NULL | 用户 |
| category_id | INT | FK→categories.id, NULL | NULL=总预算 |
| amount | DECIMAL(12,2) | NOT NULL | 预算金额 |
| month | VARCHAR(7) | NOT NULL | YYYY-MM |
| created_at | DATETIME | DEFAULT NOW() | 创建时间 |
| updated_at | DATETIME | ON UPDATE NOW() | 更新时间 |

唯一约束：`uq_user_month_category` (user_id, month, category_id)

## 7. API 设计

### 7.1 规范约定

| 规范项 | 约定 |
|--------|------|
| Base URL | `https://api.dailytracker.com/v1` |
| 认证方式 | Header: `Authorization: Bearer <access_token>` |
| 请求格式 | `Content-Type: application/json` |
| 响应格式 | `{ "code": 0, "message": "success", "data": {...} }` |
| 分页 | `?page=1&page_size=20`，响应含 `total`, `page`, `page_size` |
| 错误格式 | `{ "code": 40001, "message": "...", "detail": "..." }` |

### 7.2 API 列表

#### 认证模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/auth/register` | 用户注册 | 否 |
| POST | `/auth/login` | 用户登录 | 否 |
| POST | `/auth/refresh` | 刷新 Token | 否(refresh_token) |
| POST | `/auth/send-code` | 发送验证码 | 否 |
| POST | `/auth/reset-password` | 重置密码 | 否 |
| PUT | `/auth/password` | 修改密码 | 是 |

#### 账单模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/bills` | 创建账单 | 是 |
| GET | `/bills` | 账单列表 (分页+筛选) | 是 |
| GET | `/bills/{id}` | 账单详情 | 是 |
| PUT | `/bills/{id}` | 编辑账单 | 是 |
| DELETE | `/bills/{id}` | 删除账单 | 是 |
| POST | `/bills/batch-delete` | 批量删除 | 是 |
| GET | `/bills/search` | 搜索账单 | 是 |

查询参数：`?page=1&page_size=20&type=expense&category_id=1&start_date=2026-07-01&end_date=2026-07-28&keyword=午餐`

#### 分类模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/categories` | 分类列表 | 是 |
| POST | `/categories` | 创建自定义分类 | 是 |
| PUT | `/categories/{id}` | 编辑分类 | 是 |
| DELETE | `/categories/{id}` | 删除分类 | 是 |

查询参数：`?type=expense` 筛选收入/支出分类

#### 报表模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/reports/weekly` | 周报表 | 是 |
| GET | `/reports/monthly` | 月报表 | 是 |
| GET | `/reports/custom` | 自定义时间报表 | 是 |

查询参数：
- 周报：`?date=2026-07-28`（返回该日期所在周）
- 月报：`?month=2026-07`
- 自定义：`?start_date=2026-07-01&end_date=2026-07-28&category_id=1`

#### 预算模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/budgets` | 获取预算 | 是 |
| PUT | `/budgets` | 设置/更新预算 | 是 |

查询参数：`?month=2026-07`

#### 用户模块

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/users/profile` | 获取个人信息 | 是 |
| PUT | `/users/profile` | 更新个人信息 | 是 |

### 7.3 错误码定义

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 40001 | 参数校验失败 |
| 40100 | Token 过期 |
| 40101 | Token 无效 |
| 40300 | 无权限访问 |
| 40400 | 资源不存在 |
| 40900 | 资源冲突（如用户名已存在） |
| 42900 | 请求过于频繁 |
| 50000 | 服务器内部错误 |

## 9. 风险与约束

### 9.1 潜在风险

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 报表查询性能 | 数据量大时报表生成慢 | 数据库索引优化 + 报表数据预聚合 + Redis 缓存 |
| 数据安全 | 用户财务数据泄露 | 全链路 HTTPS + 权限校验 + 安全审计 |
| 移动端适配 | Web 版在手机上体验不佳 | 设计阶段即采用响应式布局，触摸交互优先 |
| 浏览器兼容 | 部分浏览器样式异常 | 使用主流 CSS 特性，避免实验性 API |

### 9.2 V1.0 约束

- 仅支持人民币 ¥，不支持多币种
- 仅支持单账本，不支持多账本
- 仅支持邮箱注册，手机号注册留待后续版本
- 不支持家庭共享账本
- 不包含语音输入功能
